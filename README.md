## `06 // DEVELOPMENT_PROTOCOL`

```text
[01] DEFINE      → turn the idea into a concrete target
[02] ARCHITECT   → choose the smallest system that can grow
[03] BUILD       → ship in readable, testable increments
[04] VERIFY      → test real flows, edge cases and failure states
[05] ITERATE     → measure what is weak and improve it
```

> I don't consider a system *production-ready* until authentication, permissions, failure cases, deployment and observability have been verified in the real environment.
